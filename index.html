Matriks Skor Prioritas PSU

Skor maksimal 100 poin. Nilai merupakan alat bantu penyaringan awal dan tetap memerlukan verifikasi administrasi serta lapangan.

Administrasi Maks. 30

PSU belum diserahkan 20; dalam proses 10; status tidak diketahui 8. Pengembang tidak aktif menambah 10 selama PSU belum diserahkan.

Kondisi Teknis Maks. 40

Jalan maksimal 20, kondisi RTH maksimal 10, dan usia perumahan maksimal 10. Setiap subaspek hanya mengambil satu kondisi terberat.

Risiko Maks. 20

Perumahan dengan catatan titik rawan genangan atau banjir memperoleh 20 poin.

Penerima Manfaat Maks. 10

Dihitung dari unit terhuni: 1–24 = 2; 25–49 = 4; 50–99 = 6; 100–199 = 8; ≥200 = 10.

Arsitektur Integrasi SIRUMAH Kota Pangkalpinang

SIRUMAH Kota Pangkalpinang merupakan dashboard data, monitoring, dan layanan perumahan dengan semangat “Satu Data, Hunian Layak untuk Semua”. Sistem ini menghubungkan database sektoral perumahan, pemetaan, kebutuhan rumah, kualitas hunian, pengelolaan RUSUNAWA, layanan masyarakat, kolaborasi, serta laporan eksekutif dalam satu antarmuka.

Sumber Data Terintegrasi

Sumber data dibedakan berdasarkan karakter data berkala dan data transaksi.

Database Excel GitHub Sepuluh sheet: PERUMAHAN, BACKLOG_KECAMATAN, RTLH_RLH_KECAMATAN, RTLH_INDIVIDU, KAWASAN_KUMUH_REKAP, KAWASAN_KUMUH_LOKASI, RUSUNAWA_UNIT, RUSUNAWA_RETRIBUSI, RUSUNAWA_SARPRAS, dan KOLABORASI_RTLH.
Google Sheets Layanan Form Layanan & Pengaduan dikirim melalui Google Apps Script dan direkap berdasarkan status penanganan.
GitHub Pages Menyajikan dashboard dan memuat workbook terbaru dari folder data tanpa menggunakan data contoh bawaan.

Cakupan Menu SIRUMAH

Setiap menu menggunakan sumber data dan fungsi yang sesuai.

1. BerandaRingkasan KPI tematik dan persoalan operasional yang memerlukan tindak lanjut.
2. Data PerumahanData kawasan perumahan, unit, pengembang, status PSU, koordinat/GeoJSON, serta Peta Analitik SIRUMAH.
3. BacklogBacklog Kepemilikan dan Backlog Penghunian per kecamatan sebagai dua indikator yang berbeda.
4. RTLH & RLHData agregat kualitas rumah per kecamatan dan data individu usulan RTLH khusus Mode Internal.
5. Kawasan KumuhRiwayat penetapan, perkembangan luas, lokasi terkini, peta, dan kesiapan data spasial.
6. PSURekap penyerahan PSU, isu teknis, lingkungan perumahan, serta ranking prioritas berbasis matriks.
7. RUSUNAWAData unit, tingkat hunian, retribusi, kondisi bangunan, dan sarana prasarana.
8. Layanan & PengaduanForm layanan publik, rekap status penanganan, dan rincian operasional khusus Mode Internal.
9. KolaborasiKontribusi lintas sumber pendanaan dalam penanganan RTLH dari tahun ke tahun.
10. Integrasi SIRUMAHPengelolaan sumber data Excel, validasi workbook, tata kelola akses, dan arsitektur integrasi.
11. LaporanRingkasan indikator aktif dan generator narasi eksekutif untuk kebutuhan internal.

Tata Kelola, Akses, dan Penggunaan Data

Prinsip penggunaan dashboard untuk publik dan petugas internal.

Mode Publik Menjadi tampilan awal dan hanya memperlihatkan menu, kolom, kartu, serta rekap yang telah ditetapkan untuk masyarakat.
Mode Internal Diakses menggunakan PIN untuk membuka informasi teknis, data rinci, integrasi, laporan, cetak/PDF, dan ekspor CSV.
Ketersediaan Data Sheet yang belum terisi ditampilkan sebagai belum tersedia, bukan dianggap sebagai nilai nol resmi.
Pemetaan Data tanpa koordinat maupun GeoJSON tetap masuk rekap dan profil objek, tetapi belum dapat ditampilkan secara spasial pada Peta Analitik di menu Data Perumahan.
Prioritas Penanganan Skor prioritas merupakan alat bantu penyaringan awal dan tetap memerlukan verifikasi lapangan, status aset, kewenangan, serta kesiapan anggaran.
Perlindungan Data Data pribadi dan informasi internal tidak boleh ditempatkan pada repository publik atau diekspos melalui menu publik.
